# Mentora
Mentora é uma plataforma web FullStack que reúne professores particulares para dar aulas de reforço de qualidade por um preço acessível.

## Sobre o projeto

A ideia do Mentora é facilitar o acesso a aulas particulares de reforço escolar, conectando alunos que precisam de ajuda a professores qualificados, de forma simples e com preços justos.

## Tecnologias utilizadas - Ainda em definição.

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Banco de Dados:** SQL

## Funcionalidades - Ainda em definição.

- [ ] Cadastro de alunos e professores
- [ ] Busca e filtro de professores por matéria
- [ ] Agendamento de aulas
- [ ] Sistema de avaliações
- [ ] Área de perfil (aluno/professor)
